# パーソナルホームページ

お気に入りのサイトやメモを、色分けしたウィンドウにまとめるシンプルなHTMLアプリです。

## ファイル

- [PC版の使い方](./usage-pc.md)
- [モバイル版の使い方](./usage-mobile.md)
- [PC版ページ](./personal-homepage.html)
- [モバイル版ページ](./personal-homepage-mobile.html)

## データについて

ウィンドウや背景の設定は、ページを開いたブラウザーのローカルストレージに保存されます。GitHubにはHTMLファイルと説明書が保存されますが、ブラウザーに保存したウィンドウの内容や背景設定はGitHubには保存されません。PCとスマートフォンの設定も自動では同期されません。

リポジトリは非公開です。GitHub上のファイルは、リポジトリにアクセスできるアカウントでログインして閲覧してください。
